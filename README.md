# Simple Auth Plugin

The Red5 Pro Simple Auth plugin is included with the Red5 Pro Server download.

For current installation, configuration, and usage guidance, use the public Red5.net documentation:

- [Stream Manager documentation](https://www.red5.net/docs/red5-pro/users-guide/stream-manager-2-0/)
- [Simple Authentication documentation](https://www.red5.net/docs/red5-pro/users-guide/authentication/simple-authentication/)

Use the **Red5 AI skills** to help your AI coding assistant build real-time video applications with Red5 Pro and Red5 Cloud, with guidance grounded in Red5 documentation. [Download the skill from GitHub](https://github.com/red5pro/red5pro-skills) or install it by running `npx red5pro-skills` in your terminal.
